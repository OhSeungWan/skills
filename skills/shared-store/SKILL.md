# shared-store

repo 하나의 모든 워크트리가 **커밋되지 않는 개인 문서를 파일 하나로 공유**하게 만든다. 실체는 공용 git dir 안 스토어 한 곳이고, 각 워크트리의 경로들은 그리로 향하는 심링크다.

```
<repo>/.git/shared-store/          스토어 — 정본(SSOT). 그 자체가 git repo(이력·복구)
  ├─ manifest                      무엇을 어디로 링크할지 정하는 목록
  ├─ CONTEXT.md · CLAUDE.local.md · agents/ · adr/ …
  └─ .git/

<워크트리>/CONTEXT.md  ─심링크→  스토어/CONTEXT.md
<워크트리>/docs/adr    ─심링크→  스토어/adr        (디렉토리째)
```

기존 `.git/matt-context/` 스토어가 있으면 이름을 그대로 쓴다(이사하지 않는다).

## 모델

- **스토어** — 공용 git dir 안 디렉토리. 경로는 `git rev-parse --git-common-dir`로 계산하므로 어느 워크트리에서 실행해도 같은 곳을 가리킨다.
- **항목** — 링크 한 쌍. `manifest`의 한 줄이 `<워크트리 상대경로>:<스토어 경로>[:gitignore]`. 세 번째 칸이 `gitignore`면 그 경로는 커밋된 `.gitignore`가 담당하고, 없으면 `info/exclude`에 등록한다. 목록이 스토어 안에 있으므로 모든 워크트리가 항목 정의까지 공유한다. `skip:<글롭>` 줄은 그 이름의 워크트리를 검사·링크에서 뺀다 — 기본값 `skip:agent-*`가 임시 에이전트 워크트리를 걸러 `doctor`가 상시 빨간불이 되는 것을 막는다.
- **입양(adopt)** — 추적 중이거나 워크트리에만 있는 실제 파일을 스토어로 옮겨 항목으로 되돌리는 복구 동작.

## 불변식

- 스토어가 정본이고, 워크트리 쪽은 **전부 심링크**다.
- `manifest`가 가리키는 경로는 커밋하지 않는다.
- ADR을 특별대우하지 않는다 — `docs/adr`도 항목 하나일 뿐이다. ADR을 git에 추적하는 repo도 정상이며, 그 repo는 `docs/adr`를 항목에서 빼면 된다.
- 스토어 안 ADR 번호는 스토어 전역 단일 시퀀스다(워크트리별로 새 `0001`을 만들지 않는다).

## link — 세팅·재링크

**언제**: 새 워크트리를 만든 직후, 항목을 추가한 뒤, `doctor`가 `missing`·`exposed`를 낸 뒤.

`bash scripts/link.sh` — 워크트리 루트에서 실행한다. 멱등하다. 스토어가 없으면 디렉토리·`git init`·기본 `manifest`(4항목)까지 만든다. 실행할 때 링커 사본을 스토어에 `link.sh`로 심는다 — 세션 시작 훅이 그 사본을 실행하므로 플러그인 경로·스킬 버전과 무관하게 산다.

스토어에 해당 문서가 아직 없으면 `skip: <경로> (스토어에 … 없음)`을 낸다. 그 문서를 스토어 안에 만든 뒤 다시 실행하거나, 워크트리에 이미 있다면 `adopt`으로 옮긴다.

**함정**: 대상이 내용 있는 실제 파일·디렉토리면 링크를 **덮지 않고 WARN 후 skip**한다. 경고는 스크립트 출력에만 남으므로 `doctor`로 실측한다.

## doctor — 실측 (인자 없으면 이것)

`bash scripts/doctor.sh` — `git worktree list` 전체 × 항목 전체를 검사한다. 진단만 하고 고치지 않는다. 문제가 있으면 exit 1.

| 판정 | 뜻 | 처방 |
| --- | --- | --- |
| `tracked` | 추적 중인 실제 파일이라 링크가 skip된다 | `adopt` |
| `diverged` | 추적 안 되는 실제 파일이거나, 심링크가 다른 곳을 가리킨다 | `adopt` |
| `missing` | 링크가 없다 | `link` |
| `exposed` | 링크는 맞지만 ignore되지 않는다 | `link` |

스토어 자체 상태(이력 유무·커밋 안 된 변경 수·미푸시 커밋 수)도 함께 보고한다.

## adopt — 복구 (사람 확인 필수)

1. `doctor`로 대상 경로와 워크트리를 확정한다.
2. 워크트리의 실제 내용을 스토어의 대응 경로로 **옮긴다**. 스토어에 같은 문서가 다른 번호·이름으로 이미 있으면(예: 스토어 `0004` ↔ 워크트리 `0001`) 어느 쪽을 남길지 사용자에게 묻는다. 스토어 번호가 정본이다.
3. 추적 중이었다면 `git rm --cached -r <경로>`로 인덱스에서만 뺀다(내용은 2단계에서 이미 스토어로 옮겼다).
4. `bash scripts/link.sh`로 재링크한다.
5. **스테이지 상태로 멈춘다.** 커밋 메시지를 제안하고(`chore: <경로>를 공유 스토어로 이관`), 커밋은 사용자가 한다.
6. 커밋 뒤 `doctor`로 확인한다.

**함정**: `git rm --cached`는 브랜치 단위다. 다른 워크트리는 그 삭제 커밋을 받을 때까지 계속 `tracked`로 보고된다 — 각 워크트리에서 base를 받은 뒤 `link`를 1회 실행해야 끝난다.

## save — 스토어 변경 커밋

1. `git -C <스토어> status --porcelain`으로 변경을 확인하고 요약한다.
2. 변경 내용에 맞는 메시지로 커밋한다(스토어는 개인 문서 repo이므로 문서 단위로 묶는다).
3. 리모트가 붙어 있고 미푸시 커밋이 있으면 개수를 알린다. **push는 사용자 승인 후에만** 한다 — 개인 문서를 외부로 보내는 일이다.

세션 중 `CONTEXT.md`·ADR을 고쳤으면 고친 자리에서 `save`까지 해 이력을 끊지 않는다.

## tidy — 스토어 내용 정리 (제안만)

기계적으로 판정되는 세 가지를 진단하고 제안한다. 삭제·이동은 사용자 승인 후 실행한다.

- **고아** — 스토어에 있는데 `manifest`가 안 가리키는 파일·디렉토리. 아직 링크하지 않은 새 문서일 수 있으니 삭제보다 항목 추가를 먼저 제안한다. 설비 파일(`manifest`·`link.sh`·`.git`, 구버전 `link-matt.sh`·`link-context.sh`)은 고아가 아니다 — 단 구버전 링커는 `link.sh`가 심긴 뒤 지워도 된다고 제안한다.
- **죽은 항목** — `manifest`에 있는데 스토어에 없는 경로(`link`가 skip 메시지를 내는 것).
- **ADR 번호** — 스토어 `adr/` 안 번호 중복·결번.

산문 내용(용어 정의 중복, 문장 정리)은 이 스킬이 아니라 `domain-modeling`이 다룬다. `CONTEXT.md`는 용어집일 뿐이다.

## 함정 (공통)

- `git worktree add`는 심링크를 딸려오지 않는다. 새 워크트리마다 `link`를 1회 실행한다. 자동화는 세션 시작 훅이 맡는다 — 훅은 스토어에 심긴 `link.sh` 사본을 실행하고, 스토어·링커가 없는 repo에서는 조용히 종료한다. 훅이 없는 머신에서는 사용자가 자기 `settings.json`에 넣는다(스킬이 설치하지 않는다):

  ```json
  { "hooks": { "SessionStart": [ { "hooks": [
      { "type": "command", "command": "bash \"$(git rev-parse --git-common-dir)/shared-store/link.sh\" 2>/dev/null || true" }
  ] } ] } }
  ```

  훅은 심링크가 하나라도 없을 때만 링커를 돌리고, `manifest`의 `skip:` 글롭에 걸리는 워크트리는 건너뛴다.

- `git stash -u`는 심링크와 스토어 밖 파일을 함께 쓸어갈 수 있다. 스토어 경로가 걸린 워크트리에서는 stash 대신 커밋·브랜치로 옮긴다.
- 스토어는 부모 repo의 `.git/` 안에 있으므로 부모 repo를 지우면 문서도 같이 사라진다. 유실 대비가 필요하면 스토어에 private 리모트를 붙인다(`save`가 미푸시를 알려준다).
